# AI Smart Mobility & Traffic Sign Recognition System
Advanced Deep Learning Capstone Project for Real-time Autonomous Vehicle Navigation.

## 🚀 Technologies Used:
* Python, TensorFlow, Keras (CNN Architecture)
* OpenCV & Streamlit (Interactive Web UI & Computer Vision)
* Google Colab (Model Training & Evaluation on GTSRB Dataset)

## 📂 Project Structure:
* `Smart_Mobility_System.ipynb`: Complete model training and evaluation notebook.
* `smart_mobility_app.py`: Streamlit application code for real-time traffic sign detection and inference.
* `traffic_sign_model.h5`: Pre-trained Convolutional Neural Network (CNN) model weights.
